# dripp

dripp — десктопный музыкальный плеер, который объединяет поиск и воспроизведение треков из нескольких источников в одном интерфейсе.

## Возможности

- Единый поиск по нескольким музыкальным сервисам одновременно.
- Воспроизведение треков без перехода на сторонние сайты.
- Очередь воспроизведения и управление текущим треком.
- Минималистичный тёмный интерфейс.

## Стек

Проект написан на JavaScript и TypeScript с использованием Electron. Работает на Windows, macOS и Linux.

## Важно знать

Это неофициальный клиент. Проект никак не связан со Spotify, SoundCloud, YouTube, Яндекс Музыкой или их аффилированными лицами. Все товарные знаки принадлежат их владельцам.

Приложение не предназначено для скачивания или распространения музыки. Оно лишь отображает и воспроизводит контент, доступный через публичные интерфейсы сервисов.

Автор не несёт ответственности за возможные блокировки аккаунтов, удаление репозитория по DMCA или иные претензии со стороны третьих лиц. Проект создан для личного некоммерческого использования.

Некоторые источники могут перестать работать при изменении защиты со стороны сервисов. Это ожидаемое поведение для неофициальных клиентов.
